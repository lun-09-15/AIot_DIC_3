# Energy Detective 對話紀錄與提案規劃

- 日期：2026-11-13
- 專案：物聯網數據分析與應用／DIC3
- 狀態：提案階段

## 01 原始資料

正式 Word 與 PPT 已收錄於 [正式繳交庫](https://github.com/lun-09-15/AIoT_Final_Proj/tree/main/deliverables)。使用者另提供同主題的提案解析 DOCX、PDF，以及 A4 橫式資訊圖表。解析文件把 Energy Detective 與 A2Z 論文 SOP、期末專題提案規範對照，包含 A–F 摘要、三項研究問題、八篇相關研究、領域研究、三種技術表示與評估規劃。

## 02 專題定位

用戶可以問某段時間用了多少電、兩段期間有何差異、哪些時段值得查核、下一小時預估用電量，以及有哪些可採行的節能做法。每個回答應能交代使用的資料、時間範圍、計算方式和限制。

## 03 研究問題與驗證

| 研究問題 | 驗證方式 |
| --- | --- |
| RQ1 歷史特徵預測能否勝過簡單基準？ | 在相同時間切分與測試時段比較 Random Forest、Persistence 與 Daily Naive 的 MAE、RMSE |
| RQ2 Agent 能否正確完成五類任務？ | 用 30 題一般題和 20 題邊界題驗證數值、單位、時間範圍及例外處理 |
| RQ3 建議能否提供證據並揭露限制？ | 以相同題集比較開啟與關閉外部檢查的回答品質及耗時 |

## 04 決策紀錄

| 決策 | 依據 |
| --- | --- |
| 使用 UCI 單一家庭用電資料回放 | 可在已知歷史時間點重現查詢與評估 |
| 保留工具輸出及知識來源 | 讓回答中的數字與建議可以回查 |
| 工具最多呼叫 8 次，回答最多修正 1 次 | 依提案設定限制執行範圍 |
| 採用根目錄 README 與 myplan 文件目錄 | 依使用者提供的 DietSense GitHub 範例 |
| 由 DESIGN.md 彙整架構與實驗 | 對應課程的交付要求 |
