# Energy Detective 能源特務

Energy Detective 是一個家庭用電分析與節能決策的 Domain AI Agent 提案。使用者以自然語言提問，系統依歷史用電資料回答查詢、比較、異常、預測與節能建議五類任務。

## 三項核心設計

1. **用電分析工具**：以 UCI 單一家庭歷史用電資料回放情境，透過統計工具計算用電量、以 MAD 標記異常候選、以 Random Forest 預測下一小時。
2. **回答檢查**：核對回答中的數字、單位與時間範圍是否符合工具結果。發現可修正的問題時，最多修正一次。
3. **證據追溯**：記錄工具結果與能源知識來源，透過 Streamlit 呈現答案、證據與限制。
